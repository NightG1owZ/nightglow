# 个人博客后端 接口文档

> 本文档由 FastAPI OpenAPI 规范自动生成，与代码实现保持一致。

- Base URL: `http://localhost:8101`
- 所有响应统一结构 `BaseResponse<T>`：`{ code, data, message }`，`code=0` 表示成功。
- 分页响应 `data` 为 `PageResponse<T>`：`{ records, total, current, pageSize }`。
- 需登录的接口依赖 Cookie `session_id`（登录接口下发），缺失或过期返回 `40100 未登录`。
- 请求体字段使用驼峰别名（如 `articleId`），与前端一致。

## 通用错误码

| code | 说明 |
| --- | --- |
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录 |
| 40101 | 无权限 |
| 40103 | 密码错误 |
| 40104 | 账号已被禁用 |
| 40105 | 账号或密码错误 |
| 40300 | 禁止访问 |
| 40400 | 请求数据不存在 |
| 40401 | 用户不存在 |
| 40402 | 用户已存在 |
| 50000 | 系统内部异常 |
| 50001 | 操作失败（如重复点赞） |

## 通用响应结构 BaseResponse

```json
{
  "code": 0,
  "data": null,
  "message": "ok"
}
```
